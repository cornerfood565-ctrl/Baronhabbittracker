# Baron Habits

A responsive, dark titanium habit-tracking web app built with Next.js, TypeScript, Tailwind CSS and Lucide icons.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current MVP features

- Daily habit dashboard and completion tracking
- Create custom habits and categories
- Current streak calculation
- Calendar history view
- Weekly analytics
- Achievement milestones
- Challenge concept screens
- Local browser persistence using localStorage
- Responsive desktop and mobile navigation

## Planned integrations

Supabase authentication, cloud synchronization, shared social challenges, scheduled reminders and account-based backups are not connected yet. Configure Supabase keys only through environment variables when that integration is implemented.

## Deploy

Import this repository into Vercel. Framework preset: Next.js. Build command: `npm run build`.
